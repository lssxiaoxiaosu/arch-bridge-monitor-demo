# 拱桥智能监测分析与展示平台 · 原型设计 Demo

对应《实施技术方案》第 6 章（智能化监测分析与展示平台）的可交互原型，采用与方案一致的前端技术选型
（Three.js 三维引擎 + ECharts 图表 + B/S 结构），后端接口在正式版中以 Spring Boot + TDengine + EMQX 实现。

## 运行方式

双击 `启动演示.bat`（需要 Python），或在本目录执行 `py -m http.server 8090`，
浏览器访问 <http://localhost:8090/>。

> 必须通过 HTTP 访问，直接双击 index.html 会因浏览器安全策略无法加载模型。

## 功能清单（与方案功能架构对应）

| 模块 | 说明 |
| --- | --- |
| 三维数字孪生 | 加载平南三桥 BIM 模型（GLB, Draco 压缩），按实验平台 1:100 / 跨径 6 m 归一化；106 个代表性测点自动挂接到拱肋/吊杆/桥面表面；图层控制（9 个材质组）、测点类型筛选、构件拾取查询（包络尺寸/最近测点）、视角预设、线框与自动旋转 |
| 监测总览 | KPI 指标（在线测点/设备/预警/最大应变/最大索力/风速）、拱肋应变实时曲线、吊杆索力分布、桥面动位移、环境量三联图、实时预警滚动 |
| 曲线查询 | 按测点类型/测点/时间范围（1h/24h/7d）查询历史曲线，支持缩放、阈值标线、CSV 导出 |
| 预警管理 | 三级预警（400/600/800 με 等分类型阈值）、状态流转（未确认→已确认→已恢复）、导航角标 |
| 吊装模拟 | 斜拉扣挂缆索吊装工艺参数化演示：22 节段两岸对称悬拼 + 拱顶合龙段，六步工艺（起吊→走行→就位→临时连接→张拉扣索→松钩），索力监视、播放/步进/复位/倍速 |
| 设备测点 | 8 台综合采集单元 + 14 台 32 通道应变模块（含备机）台账、测点分区统计（A~F 区，与方案表 5-2 一致）、传感器类型统计 |

顶栏"模拟加载工况"按钮可触发一次 60s 加载 + 60s 卸载的演示工况，拱顶应变抬升并联动触发三级/二级预警，
用于向建设单位演示"采集→分析→预警→处置"完整链路。

## 数据说明

所有监测数值均为**演示引擎生成的模拟数据**（AR(1) 漂移 + 日周期 + 随机脉动 + 工况响应），
量级按 Q345C 钢材与模型尺度设定，仅用于原型交互验证，不代表实测结果。

```

```
